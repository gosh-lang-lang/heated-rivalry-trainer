# Heated Rivalry — тренажёр английских слов

Бриф для переноса проекта в Claude Code. Положи этот файл в корень репозитория (можно переименовать в `CLAUDE.md`, чтобы Claude Code читал его автоматически), рядом — `index.html` (текущий прототип) и `words.json` (слова).

## 0. Идея

**Пользователь:** Евгений, русскоязычный, английский B1–B2. Хорошо понимает на слух, мало практики говорения, не хватает словарного запаса. Устройства: iPhone, iPad, MacBook.
**Второй пользователь (2026-11-20):** Светлана (`svetlana`) — общий словарь, свой прогресс и уроки; создана на сервере командой `cli.ts user:add`. Приветствие на главной — по имени вошедшего (`displayName` из `/api/auth/me`, без сети — последнего вошедшего на устройстве, `hr2_user_name`); раньше там было вписано «Евгений».

**Задача:** читать в оригинале роман *Heated Rivalry* (Rachel Reid) и параллельно расширять словарный запас так, чтобы слова переходили в активную речь, а не просто «узнавались при чтении».

**Как это работает сейчас вручную:**
1. Читает страницу, подписывает перевод над незнакомыми словами.
2. Выписывает слова с переводом в бумажный блокнот (≈25–30 слов на страницу в начале книги).
3. Фотографирует страницы и блокнот → Claude проверяет переводы по контексту и добавляет слова в тренажёр.
4. Занимается в тренажёре, перечитывает страницы.

**Принципы обучения (не терять при переписывании):**
- **Маленькие порции:** новые слова блоками по 5–6.
- **Лестница сложности для каждого слова:** знакомство → узнавание (выбор) → вспоминание (вписать самому) → контекст (пропуск в предложении) → применение (собрать фразу).
- **Учим слова, а не уроки:** партия с фото — только способ добавить слова; дальше у каждого слова свой уровень и дата, повторения из всех партий вперемешку.
- **Интервальное повторение:** у каждого слова уровень и дата следующего показа. Чем выше уровень, тем активнее задание: узнать → вписать → своё предложение и сказать вслух.
- **Один урок в день из двух частей по ~15 минут:** часть 1 — учим, часть 2 — закрепляем и применяем. Часов нет: часть 1 — когда удобно. Часть 2 — после паузы: лучше не раньше чем через 90 минут после реального конца части 1 (на главной «Лучше после HH:MM» с отсчётом; это совет — начать можно сразу). Если пауза кончается позже 22:00 или уже 22:00 — «Сегодня уже поздно — часть 2 лучше завтра первым делом» (кнопка «Всё равно сейчас»). Не пройденная часть 2 переносится: назавтра (и послезавтра) главная начинается с «Урок N · часть 2» — слова того урока, итог пишется в его день, — а ниже «Урок N+1 · часть 1», второстепенно, пока перенесённая часть 2 не пройдена. Более старые непройденные части 2 пропадают. Номер урока N — сколько дней пройдена часть 1 (решение пользователя 2026-11-20: «утро/вечер» звучало так, будто учиться можно только утром).
- **Применение в жизни:** свои предложения о своей жизни с проверкой ИИ, плюс произнесение вслух.
- **Связь с книгой:** шаг «перечитай страницы» с отметкой.
- **Ошибки внутри занятия** возвращаются в конец (как в Duolingo); счёт считается по первой попытке.
- **Два вида слов — ходовые и редкие.** Все слова проходят полную лестницу (включая «впиши» и свои предложения), но редкие — реже. Делит Claude как учитель при разборе фото, пользователь не размечает (его решение). Критерий: скажет ли он это о своей жизни или в разговоре о книгах серии. Хоккейные термины и лексика, которая повторяется во всей серии *Game Changers* и в разговорах о ней (*puck, face-off, archrival, banter, slow-burn*), — ходовые. Редкие — книжные слова, которые в речи не нужны (*rambunctious, firmly ensconced, animosity, growl, sparkle*): их подкрепит само чтение серии.
- **Нагрузка под контролем:** новые слова — только когда очередь повторений в порядке; темп сам подстраивается под точность на повторениях (цель 85–90%).
- **Метрики:** точность на повторениях (главная), счёт каждого занятия, сравнение с прошлым разом, серия дней, «трудные» слова (4+ ошибок).

## 1. Текущее состояние (прототип v2)

`index.html` — один самодостаточный файл (HTML + CSS + JS, без сборки), опубликованный как артефакт Claude. Использует возможности платформы Claude через `claude.use(...)`:

| Возможность | Для чего | Что взять вместо в своей версии |
|---|---|---|
| `db` | хранит состояние в документе `state/main` | свой бэкенд (например, Supabase) + авторизация |
| `sample` | проверка своих предложений моделью Claude | Anthropic API через серверную функцию (ключ только на сервере) |
| `tts` | озвучка голосом Claude (нет в Safari и мобильных приложениях) | TTS-API или Web Speech API (`speechSynthesis`) |
| `dictation` | распознавание речи (только Chromium и десктопное приложение Claude) | Web Speech API / Whisper; на iOS — диктовка с клавиатуры |

Без этих возможностей страница всё равно работает: состояние лежит в `localStorage` (ключ `hr2_state`), озвучка идёт через `speechSynthesis`, вместо кнопки микрофона — текстовое поле.

**Экраны:**
- **Главная:** серия дней, карточки «Утро · учим» и «Вечер · применяем» (в новой версии — «Урок N · часть 1 — учим» и «часть 2 — применяем»), распределение слов по уровням, настройка «новых слов за утро» (6/12/18/24).
- **Занятие:** прогресс-бар, задание, нижняя панель «Проверить / Дальше» с цветной обратной связью.
- **Словарь:** все слова по партиям, уровень, дата следующего повторения, заметка и пример.
- **Статистика:** 14 дней (утро/вечер в %), частые ошибки, история своих предложений с исправлениями.
- **Итог занятия:** %, сравнение с прошлым разом, новые слова, минуты, серия.

**Картинки:** сейчас эмодзи (артефакт не может грузить внешние изображения). С 2026-11-21 в приложении эмодзи заменяются иллюстрациями-сценами — см. раздел 6, «Иллюстрации к словам».

## 2. Модель данных

### Слова (`words.json`)
```jsonc
{
  "version": 1,
  "batches": [{ "id": 1, "title": "Отзывы критиков", "pages": "отзывы критиков (стр. 1)" }],
  "words": [{
    "id": "sacred",                 // slug от en
    "batch": 1,
    "picture": "🙏",
    "en": "sacred", "ipa": "/ˈseɪkrɪd/", "ru": "священный",
    "note": "…",                    // пояснение / поправка
    "example": "For him, Sunday morning is sacred.",
    "exampleRu": "Для него утро воскресенья — святое.",
    "blank": "sacred",              // точный фрагмент example, который прячется в задании «впиши»
    "correctionOfMyTranslation": true,  // перевод в блокноте был неточным
    "rare": false,                      // редкое книжное слово (нет поля — ходовое)
    "quote": "…", "page": "12"          // оригинальная фраза со страницы и её номер (с новых партий)
  }],
  "sentences": [{ "en": "…", "ru": "…", "words": ["devour", "entire", "novel"] }]  // банк фраз для сборки
}
```

### Состояние пользователя (`state/main`, тот же формат в `localStorage` → `hr2_state`)
```jsonc
{
  "upd": 1763650000000,                       // ms, время последнего изменения копии
  "reset": 0,                                 // ms, когда прогресс сброшен (progress:reset); 0 — никогда
  "settings": { "newPerDay": 12, "voice": "af_heart", "look": "ice", "theme": "system", "avatar": "" },   // личные настройки — общие для всех устройств
  "settingsAt": { "newPerDay": 1763650000000, "voice": 0 }, // когда менялся каждый пункт; слияние — по пунктам
  "srs": { "<wordId>": { "lvl": 0-6, "due": "YYYY-MM-DD", "intro": "YYYY-MM-DD", "right": 0, "wrong": 0 } },
  "days": { "YYYY-MM-DD": {
      "morning": { "score": 34, "total": 38, "mins": 14, "newN": 12, "at": "ISO" },
      "evening": { … }, "extra": [ … ], "reread": true } },
  "sent": [{ "at": "ISO", "words": ["endure"], "text": "…", "ok": false, "corrected": "…", "comment": "…", "pending": false }]
}
```

### Интервальное повторение
- Интервалы по уровню: ходовые `[0, 1, 3, 7, 14, 30, 60]` дней, редкие `[0, 2, 6, 14, 30, 60, 120]`.
- Знакомство со словом: `lvl=1`, `due=сегодня+IV[1]` (ходовое — завтра, редкое — послезавтра), `intro=сегодня`.
- Повторение, первая попытка верна: `lvl=min(lvl+1,6)`, `due=сегодня+IV[lvl]`.
- Ошибка: `lvl−2`, не ниже 1; проверка скоро — `due=сегодня+IV[1]` (ходовое — завтра, редкое — послезавтра). Не до 1: забытое слово восстанавливается быстро.
- Проверка в части 2 («впиши» без подсказок), ошибка: то же, что ошибка на повторении.
- Группы для UI: новые (0), учу (1–2), знакомо (3–4), выучено (5–6).
- Порядок повторения: сначала просроченные (старые раньше), затем сегодняшние от низкого уровня — если всё не поместится, первыми идут самые непрочные.
- «Трудное» слово — 4+ ошибок (`isHard`). Разбирая новую партию, Claude добавляет к трудным новый пример, ассоциацию или сравнение с похожим словом.

### Темп новых слов (`newToday` в `core/plans.ts`)
- По умолчанию — настройка «новых слов за урок» (6/12/18/24).
- Точность на повторениях за 7 дней (`revScore/revTotal` в итогах занятий, нужно ≥20 повторений): ниже 80% — только 6 новых; 95%+ — на блок больше настройки.
- Очередь на сегодня больше 60 — новых нет; больше 20 — не больше 6. Причина видна на главной.
- Модель на 1000 слов (`core/model.test.ts`, настоящие функции): при 85% верно все слова введены к ~161-му дню, очередь не больше ~64, повторения не опаздывают; при 75% — к ~201-му дню.

### Состав занятий
- **Часть 1 — учим** (данные — `days[d].morning`, занятие `morning`; ключи остались от «утра», миграции нет): до 40 слов на повторение (`lvl 1–2` — выбор перевода или аудирование, `3` — вписать в пропуск с подсказкой, `4+` — без подсказки), затем новые блоками по 6: `intro` ×6 → `pick` ×6 → `pairs` → `listen` ×3 → `type` с подсказкой ×6 → `build` ×3 (из банка фраз, где все слова уже известны, иначе из примеров).
- **Часть 2 — применяем** (`days[d].evening`, занятие `evening`): до 20 повторений на сегодня, не поместившихся в часть 1 (без слов самого урока) → `type` без подсказок по словам урока — выученным в день урока (до 12; `eveningPlan(…, day)`: у перенесённой части 2 — вчерашние слова, повторения — на сегодня) → `write` ×3 (`writeGroups`: 1–2 ходовых слова из сегодняшних; одно старое ходовое слово уровня 5+, с которым дольше всех не писали, — применение через недели; одно редкое уровня 3+ или ещё пара сегодняшних; выученные сегодня редкие не идут; проверка ИИ) → `speak` ×2 (своё исправленное предложение, порог 80% слов) → `reread`.
- **«Ещё 6 новых»** после части 1 — только блок новых слов; кнопки нет, пока остались повторения на сегодня.
- Ответ в `type` сравнивается после нормализации; для слов длиннее 5 букв принимается одна опечатка (расстояние Левенштейна = 1).

### Промпт проверки своего предложения (сейчас)
Модели передаются целевые слова и текст ученика. Она возвращает JSON: `{"ok": bool, "corrected": "...", "comment": "1–2 предложения на русском"}`. `ok=true` — только если нет ошибок и целевое слово употреблено верно.

## 6. Статус (2026-11-20)
**Фаза 1 — каркас готов.** `app/`: `npm install`, `npm run dev`, `npm test`, `npm run build`.
- `app/src/core/` — чистая логика без DOM: `srs.ts` (интервалы, уровни, серия), `plans.ts` (состав частей 1 и 2 урока), `lesson.ts` (расписание урока: пауза, «поздно», перенос части 2), `session.ts` (оценка по первой попытке, возврат ошибок в конец, итог), `text.ts` (нормализация, Левенштейн, говорение), `state.ts` (импорт и экспорт, слияние по `upd`), `check.ts` (промпт и разбор ответа ИИ). 52 юнит-теста.
- `app/src/screens/` — главная (вкладка «Главная», до 2026-11-21 — «Сегодня»), занятие (все 9 типов шагов), словарь («Слова»), «Путь», «Я» (коллекция, достижения, статистика), итог: перенесены 1:1 со стилями прототипа.
- **Прогресс — на сервере** (`server/progress.ts`, таблица `progress` в той же `auth.db`, `GET/PUT /api/state`), у каждого пользователя свой. Браузер — только кэш (`localStorage` → `hr2_state:<имя>`) для мгновенного старта и работы без сети. Синхронизация (`src/lib/sync.ts`): побеждает более новый `upd`; забираем при запуске, возвращении в приложение и появлении сети, отправляем после каждого изменения. Прогресс, живший только в браузере (`hr2_state`), при первом входе забирает вошедший и отправляет на сервер. Ручного экспорта и импорта в приложении нет: перенос между устройствами — через сервер, резервные копии — ежедневный бэкап базы.
- **Бэкапы:** мак раз в день снимает копию базы в `~/Backups/heated-rivalry/` (одна на день), хранит 3 последних дня (`deploy/backup.sh`, задача launchd — `deploy/backup-install.sh`). Восстановление — `deploy/README.md`.
- Озвучка: нейросеть **Kokoro** на своём сервере (`app/server/`, `npm run server`, порт 8787; в dev Vite проксирует `/api`). `POST /api/tts {text, voice}` → `{url}` → MP3 из кэша `server/cache/tts/`; новая фраза генерируется ~1 с в отдельном потоке, из кэша отдаётся за миллисекунды.
